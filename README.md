# PGCR Stats Extension

Extended view for stats on raid.report and dungeon.report profiles and PGCR pages.

## Installing the extension

### Chrome

* Download the `pgcr-stats-extension.zip` file from the [releases page](https://github.com/distaste4596/pgcr-stats-extension/releases/latest)
* Extract the `pgcr-stats-extension.zip` file to a folder on your computer.
* Open Chrome and go to the URL `chrome://extensions/`.
* Enable "Developer mode" by toggling the switch in the top right corner.
* Click the "Load unpacked" button.
* Select the folder where you extracted the zip file.

### Firefox

* Download the `pgcr-stats-extension.zip` file from the [releases page](https://github.com/distaste4596/pgcr-stats-extension/releases/latest)
* Extract the `pgcr-stats-extension.zip` file to a folder on your computer.
* Open Firefox and go to the URL `about:addons`.
* Click the gear icon and select "Install Add-on From File...".
* Select the `.xpi` file from the folder where you extracted the zip file and click "Add".
